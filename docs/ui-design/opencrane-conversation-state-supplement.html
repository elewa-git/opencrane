A2UI — direct upstream pin, eleven-component catalogue, and authorized actions

Versioned transport contract

Retain the in-process sink, delete its OpenClaw version lockstep, and pin the supported upstream A2UI packages directly.

catalogue
Exactly eleven server-admitted standard components. Unknown component names render a safe unsupported placeholder.
surfaceUpdate
Creates or updates component trees progressively within one fenced surface.
dataModelUpdate
Updates display data only; it never grants a command or approval.
CUSTOM envelope
Version + conversation id + run id + message id + surface id + sequence. Raw provider/runtime payloads are rejected server-side.
userAction
Emits an intent carrying the displayed action id. The authenticated server reconstructs authority and returns the canonical result.
